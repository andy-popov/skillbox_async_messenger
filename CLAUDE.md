# skillbox_async_messenger

## Еженедельная рассылка GREENCOF NEWS

Регламент, структура письма и чек-лист — в `newsletters/REGLAMENT.md`. Читать его перед сборкой
любого выпуска: порядок блоков согласован, новые рубрики не придумываем.
Готовые выпуски лежат в `newsletters/<дата>_<NN>WEEK<год>/`.

## telegram-mcp-server

MCP-сервер для Telegram Bot API, зарегистрирован в `.mcp.json`. Требует `TELEGRAM_BOT_TOKEN`
в окружении и `npm install && npm run build` в `telegram-mcp-server/`.
