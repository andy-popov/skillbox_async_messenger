# Правила для Claude

## Задачи в Битрикс24 по ходу работы

Договорённость с Андреем Поповым: любую работу, которую мы делаем вместе, Claude
ведёт задачей в Битрикс24 в реальном времени. Скрипт — `.claude/b24_task.py`
(на Windows вместо `python3` — `python`).

1. **В начале** работы по новой просьбе (не по уточнению к текущей) ставь задачу
   и запомни её id:
   `python3 .claude/b24_task.py start "Короткий заголовок" "Что делаем и зачем"`
2. **По ходу**, после каждого заметного шага (коммит, пуш, PR, найденная причина,
   готовый файл), пиши комментарий со ссылкой, если она есть:
   `python3 .claude/b24_task.py comment <id> "Что сделано"`
3. **В конце**, когда результат сдан, закрывай задачу с итогом:
   `python3 .claude/b24_task.py done <id> "Итог и ссылки"`

Вебхук скрипт берёт из `B24_TASKS_WEBHOOK`, а если её нет — из `B24_WEBHOOK_URL`
(основной вебхук моста, права на задачи у него есть).

Если скрипт выходит с кодом 2 (вебхука нет или Битрикс отказал), один
раз скажи об этом Андрею с текстом ошибки и продолжай работу — сбой постановки
задачи работу не останавливает. Адрес вебхука никогда не печатай и не проси
прислать в чат: он хранится только в переменной окружения.
