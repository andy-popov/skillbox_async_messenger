# Анонс-рассылка: «Перенос даты доставки заказов»

Материалы для рассылки в Битриксе по новости
<https://lk.greencof.ru/news/sobytiya/perenos-daty-dostavki-zakazov/>.

> Оригинал новости не был прочитан: домен `lk.greencof.ru` недоступен из окружения,
> в котором готовился текст (egress-прокси отвечает 403). Текст написан по теме новости,
> конкретика вынесена в плейсхолдеры — их нужно заменить фактическими данными из новости.

## Файлы

| Файл | Назначение |
| --- | --- |
| `email.html` | HTML-версия письма (таблицы + инлайновые стили, ширина 600 px) |
| `email.txt` | Текстовая версия — для alt-part и для мессенджер-каналов |

## Плейсхолдеры — заменить перед отправкой

- `{{ДАТА_СТАРАЯ}}` — плановая дата доставки
- `{{ДАТА_НОВАЯ}}` — новая дата доставки
- `{{ПРИЧИНА}}` — причина переноса (например, «праздничными днями», «изменением графика работы склада»)
- `{{ПЕРИОД_ЗАКАЗОВ}}` — какие заказы затронуты (например, «с 1 по 5 сентября»)
- `{{ДЕДЛАЙН_ЗАКАЗА}}` — до какого момента принимаются заказы на эту поставку
- `{{ТЕЛЕФОН}}`, `{{EMAIL_МЕНЕДЖЕРА}}` — контакты

Если какого-то блока в новости нет (например, дедлайна приёма заказов) — строку лучше удалить,
а не оставлять пустой.

## Варианты темы письма

1. `Перенос даты доставки заказов: новая дата — {{ДАТА_НОВАЯ}}` — основной, дата сразу в теме
2. `Важно: меняется график доставки заказов` — если новая дата зависит от клиента
3. `#NAME#, ваш заказ приедет {{ДАТА_НОВАЯ}}` — персонализированный вариант для A/B-теста

Прехедер: `Заказы {{ПЕРИОД_ЗАКАЗОВ}} будут доставлены {{ДАТА_НОВАЯ}}. Подробности внутри.`

## Как загрузить в Битрикс

**Битрикс24 → CRM-маркетинг → Email-рассылка:**

1. Создать рассылку, выбрать сегмент (клиенты с заказами за нужный период).
2. В конструкторе письма переключиться в блок **HTML-код** и вставить содержимое `email.html`.
3. Указать тему и прехедер из списка выше.
4. Проверить, что макрос `#NAME#` подставляется (в Битрикс24 — поле имени контакта);
   если сегмент без имён — заменить `#NAME#, здравствуйте!` на `Здравствуйте!`.
5. Отправить тестовое письмо себе, проверить на мобильном и в Outlook.
6. Ссылка отписки: в Битрикс24 добавляется автоматически, в шаблоне оставлен
   резервный `#UNSUBSCRIBE_LINK#` — если платформа вставляет свою, дублирующий футер убрать.

**1С-Битрикс: Управление сайтом → Маркетинг → Рассылки:**

1. Новое сообщение → тип письма HTML, вставить `email.html` в поле HTML-текста.
2. Текстовую часть заполнить из `email.txt`.
3. Доступные макросы: `#EMAIL#`, `#NAME#`, `#UNSUBSCRIBE_LINK#`, `#RUB_NAME#`.

## Замечания по вёрстке

- Только таблицы и инлайновые стили — без внешних CSS и медиазапросов, чтобы визуальный
  редактор Битрикса не ломал разметку при сохранении.
- Изображений нет намеренно: письмо читается при отключённой загрузке картинок.
  Если нужен логотип — вставить `<img>` в шапку с `alt="Greencof"` и шириной не больше 200 px.
- Кнопка сделана таблицей с фоном, а не `<button>` — корректно рендерится в Outlook.
